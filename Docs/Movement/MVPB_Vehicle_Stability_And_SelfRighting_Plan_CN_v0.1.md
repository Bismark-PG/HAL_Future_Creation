## 3. 反弹诊断与修正范围

先对同一车辆、地面与墙面建立保存值／运行值基线：根碰撞形状、总缩放、质心／惯性读数、碰撞简单几何、物理材质实际来源及Restitution合并方式、线性／角阻尼；检查地面／墙接缝、重叠及去穿透速度。记录实际引擎版本与当前异步物理步长；现配置为60Hz异步物理，不把屏幕FPS当成物理步频。

以相同高度／初速度和姿态做落地、正撞／斜撞墙、球或机关击飞后落地对照。至少记录触地前后法向速度、角速度、命中对象／法线、自然NormalImpulse、规则追加DeltaVelocity、档位、Action序号及接触回合。先用开发诊断夹具隔离规则追加与自然物理，正式规则未定前不增加玩家可滥用的开关。

按证据依次处理：

1. **物理材质与接触**：先做车辆低回弹对照，并核对双方材质和合并模式。不能只将车一侧Restitution设0就假设有效接触回弹一定为0。保留球的独立弹性，避免全局改动物理设置连带改变球。
2. **规则追加**：若普通支撑／落地触发持续向上补量，区分地面支撑、墙面冲撞与显式球／机关攻击。普通支撑不应反复注入额外弹跳；落地是否消费档位／脱球及具体追加策略需在修正规格中明确，不在本计划静默改10-D规则。
3. **形状与数值稳定性**：若与深度穿透、过厚代理、尖角或解算配置有关，按实测修正对应问题，保留参数和前后对照。求解／子步调整须兼容现有网络物理步长及重模拟，不能盲目叠加子步设置。
4. **有界落地耗散／辅助**：只有前述不足时再设计局部、短时、有上限的法向／Pitch-Roll耗散或有限辅助；不让它在腾空时持续吞掉有效攻击产生的运动。

不采用全局大阻尼、每帧清零Z速度、锁Pitch/Roll、每帧SetActorRotation等方式消除所有碰撞后果。线性阻尼会影响整体平移与坠落，角阻尼会影响转向／翻滚，不能只凭“稳定了”判定无副作用。

参考：[Epic物理材质说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/physical-materials-reference-for-unreal-engine)定义Restitution及双方合并模式；[Epic物理阻尼说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/physics-damping-in-unreal-engine)区分平移／旋转阻尼。上面具体修正顺序是本项目建议，不是官方文档为本项目给出的原因结论。

## 4. 侧翻／倒扣后的操控

建议首版将“探测到地面”与“允许轮胎驾驶”分开：

- 有效地面距离、法线与坡度成立，并且车身姿态处于允许范围，才给正常驱动、刹车／倒车、抓地和转向控制力。
- 侧翻／倒扣时正常驾驶控制力关闭，保留Chaos惯性、重力、碰撞与合理被动耗散；不新增按左右键无限滚动的空中控制。
- 临界角附近采用有界迟滞或短暂稳定判定，避免每个物理步反复开关。具体阈值待按现有代理及坡面测试确定；不要用临时骨骼姿态代替物理根姿态。
- 现阶段先做窄的支撑／姿态判定，未来四点物理悬挂接管有效轮侧支撑。当前不为门控就实现整套轮胎／悬挂框架。
- 门控在物理执行路径中判定，拥有客户端预测／重模拟与服务器一致；不把“禁操控”做成只在客户端清空输入。

本次需求针对驾驶；不会顺带将发射、技能或GAS效果全部禁用。姿态变化本身是否影响自动捕球／持球／发射应单独明确，避免将翻车限制悄悄扩大成通用沉默规则。

## 5. 长按按键自救

**已确认交互：低速、持续侧翻后，长按按键自救。** 推荐以原地受限翻正为首版目标，与自然落地辅助分开；不是回出生点的重生功能。

建议流程：持续不适合驾驶且满足低线速／低角速及有效地面条件 → 允许长按并显示进度 → 服务器再次验证 → 有限力矩／力执行翻正 → 恢复有效支撑后退出。无空间、地面无效或动作超时应失败退出，不强制穿过墙／地面，也不循环施加无限翻身冲量。

- 高速飞行／仍在翻滚时不能立即清除受击结果；触发条件要保留被击翻的短暂失控后果。
- 初始方向建议尽量保留Yaw，只修正Pitch／Roll；优先采用有界物理翻正。若需安全抬升或位置纠正，须另核对空间与网络物理Teleport／历史重置机制，不能直接在Pawn Tick设置Transform。
- 不附带回血、清除Buff／Debuff、授予无敌或重置技能冷却。球的处理、受击打断与失败重试按第5.1节已确认规则执行，不能靠Attach或重生副作用隐式实现。
- 新增独立的恢复输入／请求，不占用现有Primary技能或发射输入；客户端提交意图，服务器验证当前可操作阶段、Avatar有效性、姿态、速度、长按条件及请求频率，客户端不得提交最终复位位置／姿态。
- 影响物理的动作要使用物理帧约定、请求／执行序号和必要历史状态。回放不重复扣血／脱球或再次计奖；恢复期间新冲击与动作冲突的优先级在实现前明确。

首版的侧翻稳定时长、长按时长、线速／角速门槛、执行时长、冷却／失败重试、冲击打断和球处理已按第5.1节确认；姿态阈值／坡度、探测与恢复力度等技术参数在诊断后确定合理默认值，放入第5.2节的共享配置。键位保持独立可配置入口，无新增玩法确认项。

### 5.1 首版测试规则（2026-10-21，用户已确认）

用户已接受以下三组首版规则，第一组另要求通过全局通用DA调试参数；时间均为游戏时间，参数可配置。当前只是规格定案，没有写入C++／DA。

| 规则组 | 已确认首版规则 |
|---|---|
| 触发与长按 | 有效地面附近持续侧翻／倒扣至少1秒，线速不高于150cm/s、角速不高于60°/s，才开始计算有效长按；条件持续满足并长按1.5秒后执行。松手或条件失效清空长按进度，禁止高速空中立即自救 |
| 执行与打断／重试 | 真正开始翻正后无需继续按住，单次最多执行2秒；新的外部有效Medium／Heavy冲击打断，按抗性／免疫后的档位判定，普通擦碰、地面支撑或自身翻正接触不打断。成功、被打断或执行超时后冷却3秒；长按阶段取消不产生冷却。成功提前结束，无空间不强行穿透 |
| 球／技能与既有状态 | 仅在实际翻正开始时将持球释放回Free，不成为攻击球、不额外施加发射冲量，沿用既有脱球重捕锁；翻正执行期间不自动接球、不发射、不发动新技能。已有Buff／Debuff继续正常计时，不回血、不清效果、不额外授予无敌。单纯侧翻及长按阶段仍只限制普通驾驶，不额外禁止技能／发射 |

姿态判定角度／迟滞、探测距离、恢复力矩、阻尼、材质参数及默认键位等按工程和实测选择，不要求用户逐个指定。独立恢复Input Action由代码提供入口、团队按配置文档手工接键；不复用Primary技能槽。

反弹诊断与最小接触修正已完成，保留既有落地档位／脱球和显式攻击规则；若后续几何／辅助要求改变这些规则，再说明具体影响。姿态门控与自救仍未实现。

### 5.2 全局通用DA与运行配置

用户要求将本次可调参数放进全局通用DA。采用一个窄范围的**共享车辆稳定／自救规则DA**，由项目级设置统一引用。现已实现`VehicleStabilitySettings→VehicleStabilityRules→World冻结快照`的接触组及材质引用；没有创建保存uasset。以下自救组仍为待实现规格，后续扩展同一原生类型，具体配置见[实施第3节](MVPB_Vehicle_Stability_MinimalFix_CN_v0.1.md#3-团队手工配置流程)。

| 共享配置组 | 首版内容 |
|---|---|
| 自救触发 | 持续侧翻1秒、最大线速150cm/s、最大角速60°/s、长按1.5秒 |
| 执行／重试 | 最大执行2秒、执行结束后冷却3秒、最小外部打断档位Medium |
| 姿态／支撑 | 允许驾驶与侧翻的角度／迟滞、坡度／探测门槛，诊断后填写默认值 |
| 翻正响应 | 有界恢复力矩／力、角速度上限及结束容差，依据真实Solver测试填写默认值 |

参数均附单位、有效范围、有限值与跨字段校验。资产只保存规则数值；每辆车自己的侧翻计时、长按进度、冷却、执行状态与请求序号保留在运行实例，不写回共享DA。

共享DA保存本轮姿态／自救通用参数；现有VehicleDefinition继续保存车型几何、质量和基础驾驶参数，表现DA保存骨骼参数，Physical Material继续保存接触材质属性。需要全局选择材质时引用实际物理材质资产，避免另外保留一份不同的Restitution数值；不把既有战斗DA扩成无边界的总配置，也不为本步建设通用配置框架。

首版调试流程为：**停止本局 → 修改并保存共享DA → 重新开局应用**。初始化时加载／校验后生成纯值规则快照，物理线程不直接读取可编辑UObject；服务器权威使用所选规则，预测／重模拟端必须使用一致的快照与版本，接入时补必要的一致性检查／同步。首版不做比赛进行中的DA热修改，避免同一段物理历史前后套用不同参数。

接触组已提供创建PM／全局DA与项目级引用的Editor步骤，由团队手工配置、保存和验证；独立恢复Input Action与键位步骤待自救代码完成时补充。当前没有其他已知玩法待确认项，下一代码入口是姿态门控与自救；代理不编辑蓝图／uasset。

## 6. 验证与后续接口

本步已修正OptionalRigPreservesGameplay对保存玩家“没有Rig”的旧假设：只在运行实例的Definition副本清除Presentation。最终本机UE5.8.3普通50/50通过，保存新物理参数／361资产哈希基线；新证据见[诊断记录](MVPB_Vehicle_Stability_Diagnostic_CN_v0.1.md)，不以10月19日49/49代替本轮。

验证覆盖：平地／允许坡面正常驾驶，侧翻／倒扣／贴墙无法正常驱动，临界角不抖动；按键松开／重复请求／条件失效／高速翻滚／受击／无空间／换Avatar／断开时长按与恢复安全退出；不同姿态落地的稳定时间和反弹高度对比、球／机关既有击飞和脱球保持、手刹与加速不绕过姿态门控。具体稳定时间／反弹容差先测基线后定门槛。
