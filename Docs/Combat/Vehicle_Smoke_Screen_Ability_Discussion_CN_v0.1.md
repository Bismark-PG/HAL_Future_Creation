# 车辆主动技能：扩散黑烟（讨论稿 v0.1）

**2026-11-17 已确认并开始 Car08 施工。** 用户接受推荐参数，确认本人免疫自身屏幕干扰但仍看见世界烟云、墙阻断影响、烟内目标血条／编号／描边隐藏且普通 HUD 保留；眩晕／腾空暂停喷射，旧烟继续消散，淘汰清理。喷口实际为 Car08 车头朝上的排气管。当前规格与完成状态以 [Car08 施工记录](Car08_Smoke_Screen_CN_v0.1.md) 为准，下方保留讨论时点。

2026-11-17，日本时间。基于 `main/793f619` 及本轮进度同步。车型和技能名尚未指定。本文区分用户已提出的需求与建议，**未确认项不是施工规格；尚无实现、编译或新测试结论**。

## 1. 用户已提出的需求

- 从车头排气孔喷出黑烟，向后拉出，类似扩散打滑带的沿路留存，但扩散感更强。
- 烟中的车辆被烟遮挡；该玩家自身的游戏画面也受烟雾遮挡，UI 不受遮挡。
- 烟雾显示高于场地中的物体，包括球与机关。

“车头喷口、朝车尾喷射／拖出”是当前理解。烟的可见轮廓、区域影响和本地全画面遮挡是三个相关但不同的对象。

## 2. 建议玩法（均待确认）

- 初版只遮挡视野，不直接伤害、减速、改变抓地或冲击。物理碰撞、球命中和机关继续运行，不自动改变其他技能的锁定／视线规则。
- 喷口跟车，喷出的烟段脱离车体后留在世界中，只有短暂初始向后运动，随后扩张、翻卷、淡出；转弯不将整片烟带拉着走。
- 每段从自身喷出的服务器时间计算寿命；停止喷射后已有烟段继续到期。与 SlipperyTrail 当前整片共同截止的规则不同，不直接复制其生命周期。
- 静止、倒车都能喷；腾空／翻覆／正在自救时暂停新增烟段。眩晕期间是否继续喷、发动许可及脱离地面后的处理仍需确认。
- 推荐施放者不受自己的屏幕遮挡，但世界烟云仍遮住其车身和视线；进入别人烟区正常受影响。普通冲击免疫不自动免疫黑烟。
- 多源烟区的屏幕遮挡取最强值并设上限，离开最强源后平滑过渡到剩余来源；不能离开一片就清空其他来源。
- 推荐普通墙阻断隔墙的区域影响，不做真实流体绕墙；视觉范围与有效范围须对应。墙体规则、跨楼层和烟高需确认。
- 淘汰／换车／离场／比赛结束的默认建议是清除所属烟与相关状态；若希望已喷烟云独立留存，应另行确认。

## 3. 判定与表现边界

服务器用可复制的烟段位置、时间、扩张曲线和高度判断**车辆**是否在烟区，不用相机是否进入烟或 Niagara 粒子碰撞作为规则。俯视相机往往高于烟顶，按相机判定会漏掉正在烟中的车辆。检测考虑高速穿越以及边缘抖动，进出强度有短过渡。

Niagara 承担喷口黑烟与扩张烟团的外观。随机翻卷／稀疏边缘可有少量端间差异，但烟区主体范围和时钟不能各端独立决定。烟不是阻挡车辆或球的实体，不为烟使用复杂物理碰撞／流体模拟。

本地画面遮挡只作用于该玩家的场景视图，普通 HUD／菜单继续在其上显示，不改变相机距离、输入或技能许可。不能直接用一个无条件全局后处理体让所有玩家一起变黑；观战／旅行／离开 Avatar 时应重绑定或清理。

“显示高于所有物体”暂理解为**烟投影范围内，车辆、球、机关不能盖住烟**，不是无条件整屏覆盖。仅提高 `TranslucencySortPriority` 不能当作完整实现保证：它主要排序半透明对象，实体深度及之后的后处理描边仍需处理。是否允许覆盖高墙／墙后区域，尚未确认。实现方案需通过真实渲染小样验证，不预先承诺只改一个排序值即可完成。

现有 Damage Feedback 采用后处理红闪／描边，Impact Burst 另有接触爆点。必须定义它们与烟的合成顺序，避免烟内车身被红色轮廓重新揭示。屏幕空间的头顶血条、编号、球标记同样可能暴露目标；“UI 不遮”是否包含这些世界目标标识，需用户确认，不能自行隐藏。

## 4. 技能 DA 的拟配置项

以下仅为首测建议，未写入 C++ 默认或现有资产。

| 分组 | 参数与建议 |
| --- | --- |
| 时间 | 喷射 4 s；每段存留 6 s（含末尾 1 s 淡出）；冷却 18 s，从发动起算 |
| 喷射 | 排气孔挂点／偏移、初始向后速度、初始运动时间、采样距离与间隔 |
| 区域 | 初始半径 100 cm、最大半径 350 cm、扩张 1.2 s、有效高度及边缘过渡宽度 |
| 世界烟云 | Niagara／材质引用、浓度、深浅灰黑颜色、翻卷与扩张速率、边缘柔和度 |
| 受影响画面 | 最大遮挡强度建议先试 0.8，淡入 0.2 s／淡出 0.5 s；动态烟纹覆盖场景，UI 保留 |
| 规则 | 自身影响、同源／多源合并、墙体与高度策略、眩晕／腾空／退场策略 |
| 预算 | 最大烟段、最大片区与粒子数、远距离细节；四人同时释放时必须有限 |

世界烟云浓度与玩家屏幕遮挡强度应独立可调。原地持续喷射不能无限增加粒子／浓度，重叠也不应将最大遮挡强度无限相乘。

## 5. 待确认后才能收敛的事项

1. 对应车型与车头喷口；是否确实从前部喷口朝后喷射。
2. 施放者是否免疫自己的屏幕遮挡；免疫时是否接受世界烟云仍遮住自身车辆。
3. 是否要求烟覆盖高墙本身／墙后的物体；墙是否阻断扩散与区域影响。
4. HUD／菜单不遮是否允许烟内目标的头顶血条、编号、球标记和透视轮廓隐藏。
5. 每段独立寿命与上述首测时间／范围／浓度是否接受；屏幕是否允许完全遮黑。
6. 眩晕／腾空期间喷射和淘汰／离场后烟的保留策略。

## 6. 实现边界与后续顺序建议

沿用车型 Definition 的 Primary 授予、GA 许可／冷却、服务器轻量烟区 Actor、目标 ASC 独立视野状态及本地表现。烟 Actor 默认不拥有 ASC。沿用现有 `FHALVehicleFXMount` 做外观挂点，权威区域来源不依赖客户端粒子或不稳定的视觉骨骼更新。

先确认本页边界，并做“小样能覆盖实体／透明球特效／受击后处理但保留 UI”的渲染验证；再完成区域、生命周期与 GAS 状态；随后接入 Niagara 与本地画面过渡；最后测多源、边缘、高速穿越、四人同放、晚加入、旅行清理与性能。当前没有开始任何一项实现。

渲染约束参考 Epic 官方的[透明材质说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-transparency-in-unreal-engine-materials)与[材质属性说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-material-properties)，同时核对本机 UE5.8.2 `UPrimitiveComponent::TranslucencySortPriority` 注释。外部文档页面版本可能更新，最终实现以团队统一的 5.8 补丁及真实渲染验证为准。
