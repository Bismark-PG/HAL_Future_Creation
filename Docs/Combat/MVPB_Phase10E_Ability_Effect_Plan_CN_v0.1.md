# MVP-B 10-E：主动冲击免疫与持续GE规格（v0.1）

日期：2026-10-16（Asia/Tokyo）。基点`main / 663e1b0`，引擎本机5.8.2。**用户已确认核心玩法规则；本文件为10-E规格，主动GA／免疫GE／冷却GE尚未编码或验收。** 同轮独立交付`HALSpawnBall`调试命令，不将该命令当作技能实现。接续入口见[Project_Status](../Project_Status_CN.md)。

## 1. 已确认规则

| 项目 | 规则 |
|---|---|
| 技能结果 | 自身获得8秒冲击免疫；使用现有`State.Combat.ImpactImmune`语义 |
| 免疫边界 | 所有来源的规则击退／击飞／脱球被抑制；保留自然Chaos推挤、阻挡与碰撞减速，不免伤，不撤销已执行冲量 |
| 冷却 | 服务器接受发动时开始20秒；例如t=0发动，通常t=8免疫到期，t=20可再次发动，不是t=28 |
| 同类效果重复施加 | 刷新为从本次成功施加起再持续8秒，不叠加成16秒、不增加免疫强度 |
| 未来叠层GE | 叠层／刷新策略属于各自GE定义；本技能只限制自己的免疫GE，不全局禁用叠层 |
| 退出 | 退出时清理本次授予的能力／效果，不遗留免疫或定时器 |

冷却期间重复按技能不算成功施加，不能借此刷新或绕过20秒。其他合法入口再次施加同一免疫GE时，才适用刷新规则；它不自动重置这项主动技能的冷却。

其余沿用现有边界：在Playing且拥有可用车辆Avatar时允许发动，持球／驾驶本身不阻止发动；服务器决定是否成功，客户端不先给自己有效免疫。现阶段HP=0不等于正式淘汰；正式死亡资格留到后续规则。免疫目标可能在拾取锁到期后正常捕获Free球，独立命中目标禁捕仍延期。

## 2. 职责与扩展约束

- 一个可复用主动GA负责激活许可、冷却提交和效果施加；无逐帧Tick，不能直接读键盘或移动刚体。输入请求仍经过所属玩家和GAS许可。
- 免疫GE与冷却GE分别管理生命周期。免疫GE按目标聚合、上限1且重复成功施加刷新时长；未来其他GE可自行配置层数、按来源聚合、刷新与到期策略。
- 免疫GE授予现有免疫Tag，不以`TierReduction=3`冒充免疫。结束时按该效果句柄移除自己的贡献，不能清空其他来源或调试命令授予的同名Tag。
- 由现有PlayerState ASC持有能力，当前Pawn是Avatar。能力授予须可重复绑定而不重复授予；Pawn失效时取消动作并移除Avatar作用域的免疫。冷却在仍存活的PlayerState上保留剩余时间，避免换Avatar刷新冷却；退出销毁Owner时一并清理。这是遵循现有Owner／Avatar边界的实施约定，不增加重生系统。
- 8秒／20秒和相关效果引用可配置；只为首个技能建立所需的窄接口，不预建完整技能树、装备栏、道具库或通用Buff管理器。
- Combat Resolver／Impact Receiver继续在命中时读取有效免疫；物理动作重放不重复查询GAS、扣血或脱球。加速／低抓地进入物理历史仍归10-F。

## 3. 施工与验证顺序

1. 定义GA、免疫GE、冷却GE和所需语义Tag／配置；独立验证8秒到期、20秒冷却及重复请求拒绝。
2. 接入能力授予／Avatar生命周期和本地激活请求，完善只读状态显示及可关闭日志；正式按键／轻量表现接线在该步骤给团队操作说明，不直接修改资产。
3. 验证重复施加刷新、多个免疫来源互不误清除、主动驱散与自然到期、退出及Avatar失效清理；另用可叠层GE测试夹具证明没有把所有效果写死为不叠层。
4. 双进程互换发动者／受击者，验证免疫期间仍扣伤害且无规则冲击／脱球，到期后恢复；重复输入不多施加或重开冷却，再补既定网络扰动回归。

示例时间线：t=0技能成功；t=4由合法独立入口再次施加同一免疫GE；免疫改为t=12到期，技能冷却仍t=20结束。技能按键在t=4会被冷却拒绝，不能触发这次刷新。
