# Car03 主动技能「战斗陀螺」设计 v0.1

2026-11-09，量产阶段首个完整主动技能。参考基点 `main/2644859`，UE 5.8.3-58210709。本文记录规则、程序实现分工、Editor 接线及验证。Car03 的保存资产由团队按第 7 节配置。

## 1. 已确认的设计

- Car03 通过主技能键变成高速自转的陀螺。持续期间禁用手刹漂移，保留油门、普通刹车和转向。旋转车辆接触其他车辆时，将对方弹开并造成少量伤害。
- Car03 在持续期间抗击飞，同时仍可受到水平方向的推力。撞普通墙时获得更明显的反弹。持球时发动技能立即高速发射，旋转时碰到球也能高速甩出，视为 Car03 的一次发射。
- **固定时长、不可叠加。** 活跃期间重复按键不刷新。
- **眩晕中、自救执行中、倒扣或腾空时无法发动。已发动后收到眩晕，技能继续，车辆无法主动驾驶，外观保持自转。** 眩晕期间保留惯性、受击位移、抗击飞、撞车与甩自由球能力。持续时间按服务端游戏时间照常推进，到期直接恢复普通形态，眩晕则按自身时长结束。若先解除眩晕且技能仍在，立刻恢复技能期间的驾驶权限。
- **技能活跃中允许按现有条件长按自救，自救执行优先。** 翻身期间保留陀螺外观、抗击飞和计时，暂停陀螺的撞车伤害与推送、自由球甩出和额外墙反弹。普通物理接触和原有自救打断条件照常处理。自救结束时，技能若仍有效就恢复接触能力，沿用本次发动的命中记录。若技能先到期，则直接结束陀螺状态，自救按原规则继续。
- **陀螺期间的持球高速发射、自由球甩出均不附加发射后坐力。** 普通墙反弹仅追加水平速度，不额外上抛。刚体已有的垂直速度继续由物理处理。
- 普通水平推开后仍可保持旋转。淘汰、换车和离场清理旧车的陀螺状态及接触记录。
- 两台陀螺互撞时，双方各对另一方结算一次小伤害和水平推送，双方的抗击飞均生效。使用各自独立的攻击记录，并在同一接触上先采集两边资格、再结算，避免回调先后决定谁能反击。

## 2. 接触规则草案

| 接触对象 | 推荐实现 |
|---|---|
| 对手车辆 | 服务器以实际接触方向建立专用技能命中，经 CombatResolver 分别结算少量伤害和冲击。三档制度保留，水平距离用独立推送预设调。每次发动对同一辆车最多结算一次，且同一接触只走一条规则冲击路径。Chaos 仍负责真实刚体接触。 |
| 来袭冲击 | 推荐保留原有效档位和水平推送，按目标当前陀螺状态跳过额外上抛和翻滚。已有伤害免疫、冲击抗性、其他来源的全冲击免疫及脱球阈值沿用原有规则。普通接触仍可能因刚体物理产生额外姿态变化。 |
| 普通墙面 | 用接触法线的水平分量判断是否撞入，保留切向速度，按入射速度算有上限的水平反弹，只补足 Chaos 已提供的反弹以外的差值。附加速度仅作用于水平面。用最小入射速度和接触去重区分正撞、擦墙与贴墙。地面／坡面支撑不走墙反弹，墙角同一碰撞段只取一个主反弹。 |
| 电墙和其他特殊机关 | 推荐机关优先。电墙保留独立的回弹、眩晕及电击表现，陀螺进入失去驾驶输入的旋转状态，避免同一接触叠加两套反弹。其他机关依据各自明确的接触分类进入既有链路。 |
| 发动时已持球 | 捕获发动瞬间的物理车头方向，以较高球速从现有持球发射流程发出。沿用发射者归属、攻击快照、拾取锁、命中消费和低速回到 Free。 |
| 活跃期间碰到 Free 球 | 沿陀螺中心指向球的水平方向甩出，方向退化时回退到物理车头。需要服务器的 `Free → Launched` 入口并共用同一个发射提交函数。活跃期间由该入口接管自由球接触，普通自动捕获让位。同一球的重复接触与同帧争抢只允许一次权威转换。 |
| 对手持有的球 | 先命中持球车，由原有脱球规则决定球是否释放。建议刚脱落的球从下一物理步起才可被甩出，防止同一接触直接完成夺球和发射。 |
| 对手已发射的球 | 建议先按来袭球处理，保留其发射归属。反弹并改写归属属于独立的可选技能规则。 |

建议首版只增加球的出射速度，沿用球现有的伤害、冲击档位和水平推送配置。两种陀螺发射均跳过发射反作用，物理接触仍照常计算。高速首测覆盖近墙起手、斜擦和高延迟的发射归属。

## 3. 实现分工与 GAS 边界

| 层 | 负责内容 |
|---|---|
| 车型 Definition 与 ASC | 由 `DA_Vehicle_Car_03 → Abilities → Grants` 绑定一个 Car03 的原生 GA 或轻量派生配置，继续使用 `Input.Ability.Primary`。服务器在现有 PlayerState ASC 授予，当前 Pawn 是 Avatar 和授予来源。 |
| Gameplay Ability（GA） | 主技能输入的服务器请求入口。核对当前 Avatar、比赛权限、存活、眩晕、自救、接地／姿态、已激活和冷却，校验配置后提交发动。同一按键重送只成功一次；活跃期间再次按键不刷新。可以在提交持续效果后结束这次 GA 的输入执行。 |
| Gameplay Effect（GE）与 Tag | 一个随 Avatar 清理的限时 GE 表示陀螺状态，发放技能运行 Tag，驱动进入／到期事件。已有 Stun 是独立状态，只限制驾驶和下一次发动。冷却若采用 GE，由独立冷却标签计时。既有伤害结算仍通过 CombatResolver 与 GAS。 |
| 车辆组件与网络物理 | 监听活跃状态和 Avatar 生命周期，在权威侧处理接触与每目标去重。自救执行状态只暂停陀螺的接触处理，活跃状态与命中记录独立保留。驾驶限制与位移通过现有运动组件执行。手刹屏蔽在物理步消费输入前生效，服务端和拥有者预测／重模拟须消费同一生效边界；使用现有运动状态发布、历史及重放接口，具体字段与兼容方案在实施前核对。普通刹车及对应急刹拖尾按既有条件运行。 |
| CombatResolver 与 Impact Receiver | 服务器识别目标和接触，构造专用技能攻击和冲击请求，经现有结算链独立处理伤害、冲击抗性和陀螺受击响应。普通接触的额外规则冲击与陀螺命中需要在入口去重，防止两边 OnHit 或同帧多点接触各算一次。 |
| Ball Control 与 Ball Actor | 持球发射沿用约束释放及失败恢复。新增窄的自由球发射入口，两条入口共同写入一次 Launched 状态、发射者和攻击快照。当前发射入口只接受 Controlled，故这一段需要扩展球状态转换。 |
| Vehicle Presentation 与 AnimBP | 使用本次发动复制的服务器起点和技能转速来计算外观角度。围绕外观中心的竖直轴自转，物理车头、碰撞根和驾驶方向独立。主车头提示保持可读；车型表现配置继续描述车身模型及其基础变换。通用 Status FX 可挂附加材质／粒子。 |

```text
主技能键 → 当前车型 GA（服务端校验）
           → 陀螺持续 GE／Tag → 每车组件开始或结束技能
                                   ├→ Movement：手刹屏蔽、墙反弹
                                   ├→ CombatResolver：车辆接触结算
                                   ├→ Ball Actor：持球／自由球高速发射
                                   └→ Presentation：本地绘制自转
```

GA、GE 和 Tag 记录发动、状态与规则。接触由服务器根据物理结果判定，车辆刚体响应由运动组件排入物理步，球由自身状态机提交发射。客户端 GAS 状态用于表现和 UI，物理重模拟按服务端生效帧重放。每次发动绑定当前 Pawn 与激活标识，清理和迟到回调均核对身份。退出时先停止接受新接触并撤销本次效果，再清理去重记录、运动限制和表现；已经发出的球继续遵循既有球权生命周期。

## 4. 独立技能配置

在 Editor 中维护一份独立的陀螺技能 Data Asset，建议名为 `DA_Ability_Car03_BattleTop`，由陀螺 GA 引用。车辆 Definition 负责分配 GA 到主技能槽。技能 DA 集中编辑固定时长、冷却、接触伤害、冲击档位、水平推送预设、普通墙反弹系数／速度上下限、持球与自由球的出射速度及速度上限，以及技能专用的自转速度。GA／GE 从这份配置读取实际时长等参数；自转速度在每次发动时确定，和起点一起复制给拥有者及观察者。

## 5. 首版落地规则与调参

1. **发动后姿态变化。** 首版按倒扣、腾空仅限制发动设计。技能活跃后被撞离地或翻倒，状态按原时长继续；进入自救时按第 1 节处理。发动姿态阈值优先沿用现有接地／可驾驶观测。
2. **测试数值。** 冷却推荐自成功发动起算，具体时长、冷却、伤害、推送和球速由独立技能 DA 配置。首轮可用测试值先验证距离、联机和可读性，数值随试玩调整。

## 6. 预定验证

| 场景 | 验收点 |
|---|---|
| 发动、重复输入、到期 | 一个激活标识对应一次发动，漂移屏蔽与驾驶恢复在 Host、拥有者和观察者一致；视觉转速与物理车头分离。 |

## 7. Editor 接线与首测

1. 使用本次构建的 Editor。Content Browser 中创建父类为 `HALBattleTopConfig` 的 Data Asset，建议在 `/Game/Data/Abilities` 命名为 `DA_Ability_Car03_BattleTop`。默认值是首测起点。
2. 在现有 `/Game/Blueprints/GA` 新建父类为 `HALBattleTopAbility` 的 Blueprint，建议命名为 `GA_Car03_BattleTop`。在 Class Defaults 的 **Battle Top → Skill Config** 引用上一步 DA，保存。持续及冷却由原生 GE 执行并从同一 DA 取数。
3. 打开 `/Game/Data/MVP_B/DA_Vehicle_Car_03`，在 **Abilities** 选择 `Vehicle Definition V1`，配置唯一的 Grant。Ability 选择 `GA_Car03_BattleTop`，Input Tag 选择 `Input.Ability.Primary`，Level 填 1。继续使用现有主技能按键。
4. 在现有 `DA_Ability_Car03_BattleTop` 打开 **Presentation → Spin Rate**。默认 900°/s，可调范围 90–2160°/s。旧版本的车型表现 DA 若曾填写自定义转速，将该数值填到此字段即可，已有技能 DA 和 GA 引用可继续使用。首版由原车外观 Mesh 绕车身局部竖直轴自转，使用原有车头箭头作为方向提示。
5. 要从正常房间选车，在测试分支把 `Car_03` 登记到房间目录。旧直连图 `MVPB_NetTest` 当前会出生 Car03，可在两端加入后由 Host 开赛做快速测试。手刹限制已进入运动历史格式 4，联机双方使用同版代码与资产。

| 首测项 | DA 默认值 |
|---|---|
| 技能持续／冷却 | 5 s／20 s，冷却从发动起算 |
| 车辆接触 | 5 HP 原始伤害，Medium 档，Long 推送 |
| 普通墙反弹 | 1.15 倍水平入射速度，起算 250 cm/s，目标法向上限 2400 cm/s，接触重置间隔 0.15 s |
| 持球／自由球发射 | 4000／3800 cm/s；速度配置上限 6000 cm/s。以固定出射速度提交，方便独立调整手感。 |

在练习房检查发动、漂移屏蔽、自救、墙面和球；比赛阶段验证扣血、互撞和淘汰。开启 `hal.AbilityLog 1` 看技能开始／结束，`hal.CombatLog 1` 看 `Combat.Source.BattleTop` 的伤害、档位和实际位移响应。对方掉球后的保护至少持续当前服务器游戏帧，已发射球归属按原流程处理。

若需要为自转叠加材质或粒子，可在车辆状态 FX 测试目录用 `State.Visual.BattleTop` 关联效果定义。这个视觉 Tag 和原生自转随同一个陀螺 GE 起止。

## 8. 本轮验证

- 转速迁移复测使用 UE 5.8.3。Game 与重新链接的 Editor Target 均通过，原生 **185/185**。本机双端采用 540°/s 测试配方，Host 出站注入 80 ms，各角色 **1/1**，拥有者和观察者都读到 540°/s，渲染端复核自转及到期复位。只读检查确认保存的 `GA_Car03_BattleTop` 继续引用现有技能 DA，Car03 的 Primary Grant 正确，新字段默认 900°/s。记录见 `Saved/BattleTop/SpinRate_20261109`。
- UE 5.8.3-58210709 Win64 Development Editor 与 Game 在 R7 编译通过。原生全量 **185/185**，0 测试警告、失败或未运行。陀螺专项覆盖姿态拒绝、技能 DA 时长／冷却、两种发射、眩晕、自救暂停、互撞去重、墙反弹公式和退场。运动历史回归核对了限制在过去生效、到期解除，以及历史缺失时触发纠正。
- R6 与 R7 的生产代码相同。R6 从现有 `MVPB_NetTest` 启动实际 Car03 BP，使用进程内测试配方，Host 出站注入 80 ms。两端各 **1/1**，均确认技能复制、手刹限制及恢复、约 5 秒技能和 20 秒冷却。D3D12 Host 还检查了实际 Mesh 的自转变换和到期恢复。同期 GF7 三回合 Host／Client 各 **1/1**。日志与报告在 `Saved/BattleTop/20261109`。
- 已保留中间轮次证据。早期双端夹具遗漏 Car03，修正后覆盖实际车型。已统一从 GA 类默认配置读取技能 DA，并在原生夹具补齐物理帧的有效确认，最终报告以 R6 双端和 R7 原生为准。
- 1193 份保存资产 SHA-256 与 FX-5 基线一致，项目设置及 `.uproject` 保持。团队需在 Editor 保存 Car03 的技能 DA／GA 引用，并真人验收墙反弹距离、出球手感、自救切换及实际画面。
