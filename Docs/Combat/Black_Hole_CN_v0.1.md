# 黑洞机关 Actor

## 规则与接入

原生类 `AHALBlackHole`，Blueprintable，可直接建立 BP 子类，或由服务器生成。生成位置为圆柱中心，世界 XY 是平面，旋转和缩放不改变玩法范围。无阻挡碰撞；只吸引有效的 `ATestVehiclePawn`，包括生成者，不吸球、不扣血、不加眩晕、不强制脱球。物理场不经过攻击档位／冲击抗性结算，保留原有 Z 速度及角速度。房间不允许世界互动或车辆已退役时不施力。

用户确认的流程：生成即弱吸引，扩张至最大范围后维持，在维持期间重复准备→瞬间强拉，强拉不缩小范围。到期停止吸引并销毁。总玩法寿命＝Expansion Seconds＋Duration Seconds。第一轮强拉在扩张完成后等待一个 Pulse Interval；这是实现默认时序。间隔长于维持时间时可完全没有强拉，到期时刻优先结束，不再强拉。

| BP Settings 参数 | 原生默认 | 单位／语义 |
|---|---:|---|
| Continuous Acceleration | 120 | cm/s²，持续向心加速度，不受车重影响 |
| Pulse Delta Speed | 700 | cm/s，瞬间追加向心速度，不设持续时间 |
| Pulse Interval | 2 | 游戏秒，两次强拉间隔 |
| Expansion Seconds | 2 | 游戏秒，从 1 cm 种子半径线性扩至最大，0 表示立即全范围 |
| Duration Seconds | 8 | 游戏秒，达到最大范围后起算 |
| Maximum Radius | 700 | cm，最大半径 |

高级几何参数 Half Height 默认 200 cm，为 Actor 中心上下高度容差。范围按车辆中心判定；中心没有向心方向，不施力。紫色在中心柔化区外吸力均匀、柔化区内逐渐减弱，黄色保持原瞬间增量。多个黑洞的向心速度贡献自然相加；油门偏转选择最强的一个来源，见下方推进偏转规则。

服务器每 0.02 游戏秒定时采样，用真实间隔积分弱吸引，再经既有 `QueueImpact/FVehicleImpactAction` 将已解析的平面速度增量送入权威网络物理动作；单机使用同入口的刚体冲量分支。这些外力的网络重演使用已保存的速度增量。油门偏转另通过服务器帧盖章的 Movement 历史，在每次物理执行／重演的位置计算当地流向；历史格式现为7，两端须同版。不新增 GAS 效果、Actor Tick 或客户端命中 RPC。

这是按时间采样的弱吸引，不是连续子步力场。单次积分最多 0.1 游戏秒；服务器卡顿跨过多次强拉时只补最新一次，不集中爆发全部漏掉的强拉。每车每黑洞最多约 50 动作/游戏秒，多个黑洞的带宽／规模性能尚需实测。高速穿越小范围不保证连续扫掠命中。

共用机关生成器尚未建立，本次不建设生成器。C++ 后续通过 `SpawnActorDeferred<AHALBlackHole>`，`ConfigureBlackHole`，`FinishSpawning` 接入；配置只接受服务器且必须在 BeginPlay 前。BP 默认值不会被原生默认配置覆盖。不要从客户端直接 SpawnActor 来代替权威生成。

## Unreal Editor：建立自己的 BP

1. 编译完成后打开 Editor。在 Content Browser 新建 Blueprint Class，展开 **All Classes**，搜索 **HALBlackHole**，建立 `BP_BlackHole`。
2. 打开 BP → **Class Defaults → Black Hole → Settings**，调整上表六个主参数。Shape 的高级参数可调整 Half Height。
3. 在 **Black Hole → Debug → Debug Draw** 勾选（BP默认值或地图Actor实例均可）。Editor／BP视口中，三圈显示最大圆形范围及上下 Half Height 边界，旋转／缩放Actor不改变这些世界单位范围。游戏内显示当前生效半径的半透明圆盘、同心圈与8个向心箭头：扩张红色、准备强拉紫色、每次强拉后的0.15游戏秒黄色。只在中心上下Half Height内查询静态地面并抬高3 cm；没有地面则回退中心平面，不改变玩法范围。显示为水平平面，不逐点贴合斜坡／崎岖地形。默认关闭，Shipping无运行时debug绘制，Editor预览组件不进入非Editor构建。
4. Compile／Save，将 BP 拖入测试地图。开始游戏后立即计时并生效，到期自行移除；多人只由服务器生成及结算。
5. 不需要 Event Graph 就有完整吸引逻辑。正式特效可在 BP 增加非碰撞 Niagara／Mesh，使用下述表现事件。代码代理未创建／编辑 BP 或地图。

## 表现接口

- `On Stage Changed(New Stage)`：Expanding、PreparingPulse、Ended。强拉是瞬间事件，不是持续阶段。Ended 在自然到期及提前销毁时用于清理；不要从事件中施加玩法冲量。
- `On Field Updated(Radius Cm, Preparation Progress)`：约 50 Hz，且每游戏帧最多一次，更新圆盘／粒子半径和准备强拉强度。Preparation Progress 是上次强拉（或扩张完成）至下次强拉的 0～1 进度。
- `On Attraction Pulse(New Pulse Index)`：播放瞬时吸入、闪光或声音。客户端依据服务器复制的序号显示最新事件，网络合并可能跳号，不补播所有历史特效；晚加入不应重播旧强拉。
- 纯读 `Get Current Radius`、`Get Stage`、`Get Preparation Progress` 可用于表现查询。客户端用 GameState 服务器时钟，不修改权威规则。

延续当前柔和圆润的卡通涂鸦画风；本次只有可开关 debug 圈与 BP 表现接入口，没有制作最终黑洞材质／Niagara。结束立即移除，不新增消散时长。

### Drag 统一推进偏转（2026-11-13）

用户要求把推进偏转整合进Drag，只有处于Drag状态的车辆才改变油门推力。本轮将流场作为`FHALMovementAreaConfig::DragDrive`随同一份Drag来源注册，由MovementAreaReceiver负责多来源选强和清理；移除黑洞独立注册／移除推进流场的路径。桥接器只在ASC实际拥有`State.Movement.Drag`时将选中的流场写入权威物理快照，并监听该标签新增／移除。物理线程继续消费历史快照，不直接读取实时GAS标签，所以旧Drag帧的重演仍能恢复当时的推进方向。

当前规则：

- 有效黑洞Drag同时提供侧向抓地缩减和可选的油门偏转；离区、到期、来源销毁、车辆解绑会清理对应来源。
- **Drag Grip Multiplier=1会关闭该黑洞的Drag状态及油门偏转**。持续引力、旋转外力、入场减速与黄色瞬拉仍依原规则生效。
- 只有Slippery状态不会启用偏转。纯抓地Drag若没有流向资料，也不会凭空决定推进方向。其他C++来源可通过同一Drag配置提供自己的流场。
- 已注册流场但实际Drag标签被移除时，桥接器发布无偏转的下一份权威快照；不必等车辆离开黑洞。当前并未新增驱散技能／免疫规则，也不承诺被外部移除的GE在留区时自动补回。
- 重叠Drag的抓地仍取最低倍率，推进偏转在有效Drag来源中取最高Drive Bend Strength，同值按服务器对象ID稳定选择；两项独立选强，不相乘，不重复施加偏转。

BP参数名称、值及含义保持，显示位置改为 **Settings → Drag → Drive Bending**。更新后重新打开原BP即可找到，无需修改Event Graph；保存资产由团队自行Compile／Save。物理历史格式保持7，本轮不增加字段或新Tick，客户端与Host仍须使用同版代码。

### 推进方向随重力场偏转（2026-11-13）

用户确认目标：踩前进时，推进方向受到当地向心＋切线流场扭曲，路线往中心旋入，主动打方向可以反抗。新增 C++ 的 `FHALGravityDrive`，由黑洞按原范围采样向车辆桥接器注册，随既有权威移动参数动作／检查点／时间线传输。物理线程以自身当前位置和车辆实际前向计算目标流向，对前进推力做平面角度插值；不直接改位置、速度或车头角度。不缩短推力向量，正好逆向时也不会把油门互相抵消成零。刹车和倒车沿车头；前进加速、前进反向动量恢复及限速修正使用偏转后的推进轴，避免朝内行驶被误当倒车限速。原侧向抓地／手刹／转向仍保持，Drag仍乘选中的环境抓地倍率。

| Settings → Attraction → Drive Bending | 原生默认 | 调节意义 |
|---|---:|---|
| Drive Bend Strength | 0.85 | 0关闭；1完全沿当地流向推进；0.85取车头到流向夹角的85% |
| Drive Bend Ramp Seconds | 0.4秒 | 进入后的SmoothStep渐入，与入场减速时间独立 |
| Drive Steering Resistance | 0.75 | 打满方向减少75%的偏转；1可在打满方向时完全取回推进方向 |

当地流向用 Continuous Acceleration 与 Swirl Acceleration 的比例组成，Swirl Direction控制切线正负；速度上限仍仅限制原额外吸力，不限制油门偏转。两项加速度都为0时不注册推进偏转。中心柔化范围内逐渐减弱偏转，精确中心保持车头方向。原持续向心／旋转外力、低速朝外逃脱辅助与黄色完整冲量保留；主动打方向反抗是新的主要逃脱控制，不能只靠直踩油门期待沿原车头直线退出。

入场降速改为辅助：**原生 Entry Speed Multiplier 默认改为0.8**（保留80%原入场动量），Capture Seconds仍0.3。已保存BP中的自订值不会被代码覆盖；若团队仍保存0.05，需手动改成0.8再测，或先设1排除入场减速。重新打开Editor，在原BP Class Defaults → Settings调整新分组，再Compile／Save，不需要新增Event Graph。

多来源推进偏转不累加，按Drive Bend Strength最大者选中，同值按服务器来源对象ID稳定选择；离区／失效／到期移除自身来源，剩余来源继续生效，无剩余恢复原推进轴，不补回旧速度。切换来源／重新进入重新渐入；同来源参数变化不重置起始帧。注册、移除仍受原服务器采样时机约束（通常0.02秒），最大半径／高度另在物理端检查；扩张中的当前边界沿用原采样判定。固定黑洞主要在进入／退出时产生参数动作，不逐帧发送推进行向。历史格式6→7；必须让Host与Client重编为同版。
