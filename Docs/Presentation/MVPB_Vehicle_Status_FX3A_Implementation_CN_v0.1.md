## 1. 本步交付与范围

新增`FHALStatusFXRuntime`纯C++模型，供FX-3B的每车组件持有。模型只拥有本车来源租约、实例身份、时间和阶段，不持有Actor／ASC／材质／Niagara／共享DA，不注册Tick、定时器、RPC或复制字段。现有Pawn、电击、车辆／球／机关规则没有接入或改变；因此本步不要求团队操作Editor资产，也不会产生新的可见特效。

按[已确认方案](MVPB_Vehicle_Status_FX3_Plan_CN_v0.1.md)保留分工：B负责车辆组装、FX-1／2资源和目标生命周期，C负责ASC／调试来源与诊断；材质共存／真实粒子适配属于FX-4，旧电击接管属于FX-5。没有提前写临时Overlay覆盖路径。

## 2. 身份与调用合同

| 类型／接口 | 行为 |
|---|---|
| `FHALStatusFXRuntime` | 一车一份，不可复制／移动，防止两辆车意外共享来源身份。由所属车在Game Thread串行驱动 |
| `AcquireSource()` | 分配一个本绑定内的来源租约，尚未提交时不维持任何实例 |
| `Submit(Token, Tag, Timing, Now, InitialClockSeconds=0)` | 首次将来源绑定到一个精确的State.Visual子Tag；新实例可显式带首次观察年龄，已有实例的刷新／重入不改原时钟或包络 |
| `RemoveSource(Token, Now)` | 永久撤销该租约；其他来源仍存在则保持活跃，最后来源退出才开始结束阶段 |
| `FHALStatusFXInstanceHandle` | Binding＋Tag＋InstanceId，标识异步结果期望作用的实例，拒绝旧绑定或同Tag旧实例的资源准备结果 |
| `SetAvailable(Handle, Ready, Now)` | 独立输入资源／目标可用性；A仅处理逻辑，B仍须额外检查FX-1的Mesh绑定代次，不能只靠实例句柄接受旧Mesh回调 |
| `Advance(Now)` | 显式推进阶段，可一次跨过淡出及残留；所有时间为有限、非负、单调不减的本地秒数 |
| `GetSnapshot／GetSnapshots()` | 读取最后接受时间的值快照，包括身份、阶段、可用性、来源数、曲线时钟、阶段年龄及强度；集合按Tag确定排序 |
| `NeedsPhaseUpdate()` | 仅判断淡入包络／淡出／残留是否还需推进；等待、空闲、稳定活跃不要求周期更新。B／FX-4的动态曲线和空间更新另行判断 |
| `ResetBinding()` | 强制清空实例与租约，生成新绑定身份并重置本地时基；B在真实退场／解绑时还要释放它拥有的资源 |

Token的`IsValid()`只表示结构有效；是否仍可提交须用该Runtime的`HasSource()`。退出后要再次进入，应申请新租约，不能复用已经撤销的Token。即使同一绑定或新车的本地计数重新从1开始，绑定身份／实例序号也会阻止旧通知操作新实例。

来源数是本地视觉输入数，不是GAS叠层，也不自动增加亮度、粒子数量或伤害。同Tag活实例只接受一致的Timing快照，冲突会拒绝，不以最后一个来源覆盖全车时序；配置变更后的绑定／资源编排由B处理。

## 3. 阶段、等待与重入

没有实例用查询失败表达，其余阶段为Waiting、Active、Fading、Residue；淡入包含在Active中。

- 第一个有效提交建立Waiting实例，曲线时钟从该时刻开始。资源晚到后进入已经推进的持续段，不重播完整起手。
- 若定义本身尚未加载、暂时不知道Timing，B先保留待处理需求／租约及首次观察时间；定义到达时以当前Now提交，并给新实例传入`Now-首次观察时间`。这不倒退模型或其他Tag的时钟。年龄须有限、非负、不大于当前本地Now；仅新实例采用该值，刷新／重入始终保留已有时钟。等待需求已经结束时撤销租约，晚到定义不能复活它。
- Active强度从起始值向1按FadeInSeconds线性变化。同Tag刷新或增加来源保持时钟、实例身份和包络。
- 最后来源在资源仍可用时退出，从当前强度按FadeOutSeconds降到0；随后进入Residue，强度仍为0。残留是供后续通道消费的独立阶段，不把焦痕等同于重新提高活跃亮度。
- 淡出／残留期间新租约进入，复用尚存实例与曲线时钟，从当前可见强度重新向1过渡；完全释放后再进入才建立新实例和新时钟。
- 需求正在等待资源／目标时，最后来源退出直接撤销，不创建迟到的淡出／残留。已经在淡出的实例暂时失去目标则继续计时，恢复时只取当前阶段；过期后不会因资源迟到而重建。
- Mesh临时失效保留有效需求和实例时钟。可用性为false时快照强度为0，但不重置原时钟；再次可用时不重启原曲线。
- FadeIn／FadeOut／Residue为0时，同一次调用内完成相应边界；不保留“下一帧再清”的空实例。

`FHALStatusFXTiming`是按值传入的秒数，不是第二份可配置默认资产。模型检查非负有限数；FX-2定义现有的淡入／淡出0～10秒、残留0～30秒作者范围保持，由B从已校验的DA复制。空结构为零过渡，仅代表明确的值输入。A不采样材质曲线，只输出连续的double曲线时钟。

无效令牌、旧句柄、非法Tag／时间／Timing、同来源改Tag或活实例时序冲突均拒绝，且不推进其他实例的时钟或提前释放尾段。每次绑定内时间必须单调；换车／新World时用ResetBinding开始新时基。这个本地时钟不承诺Host／Client起始帧一致，不决定GE实际持续时间。

1. AggregationAndLeaseLifetime：重复来源不增加实例／亮度，任意撤销顺序保留其他来源，旧租约不可复用。
2. RefreshFadeAndResidueReentry：刷新保留包络，淡出／残留重入保留身份／时钟与当前强度，完全释放后才重建。
3. WaitingAvailabilityAndCancellation：晚到资源进入持续段，定义晚到可补首次观察年龄而不倒退其他时钟，等待撤销无迟到尾段，目标丢失／恢复保留既有尾段年龄，过期不会重建。
4. ZeroDurationAndSkippedPhases：零淡入／淡出／残留，以及一次Advance跨越多阶段的准确边界。
5. BindingAndVehicleIsolation：两车、绑定换代、旧来源／旧资源句柄失效，强制清理无剩余工作。
6. RejectedInputIsAtomic：非法时间／Tag／Timing、同来源改Tag、时序冲突或旧回调不修改时钟／强度／其他实例。
7. IndependentTagsAndDeterministicSnapshots：两Tag独立时钟／强度／结束，快照排序不依赖插入顺序。
8. PhaseSchedulingAndTimePartition：等待／稳定／空闲停止阶段更新，大本地时间下不同分步推进得到一致阶段与强度。
