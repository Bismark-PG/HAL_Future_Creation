# 临时车顶血条与编号 v0.1

日期：2026-11-04。由干净`main/93f18e6`接续，用户要求P1／P2等车顶编号上移，并在下面添加简单血条，供打包／联机测试使用。

## 1. 使用方式

完整编译后重新打开Editor或启动游戏，进入房间、选车并确认，即可在原生驾驶HUD看到。**无需修改车辆BP、DA或制作Widget Blueprint。** 重新打包后才会进入分发给组员的测试包。

- 编号保持原玩家颜色，以原车顶投影点为基准水平居中，上移一个字体高度加6个Slate单位。
- 血条放在编号下方，外框68×10个Slate单位，边框1；跟随现有Viewport DPI，不随车辆翻滚旋转。
- 血量比例为当前车辆`VehicleHealthComponent`读取的GAS `CurrentHP / MaxHP`，不是固定按100血计算。
- 高于50%为绿色，25%～50%为黄色，不高于25%为红色；0血显示空框。HP尚未初始化时只保留编号，不显示假零血条。
- 每个本地视口绘制当前房间成员已有Pawn的血条；车辆离开／销毁／换车后，下次绘制读取当前Pawn。没有新增HP副本、RPC、Gameplay Effect或Actor Tick。

本次只扩展现有`HALPracticeRoomWidget::NativePaint`原生编号绘制。菜单、加载、倒计时仍沿用原显示规则；使用自定义Designer Widget Blueprint时，仍以其布局为准，不额外叠画原生编号／血条。正式复杂HUD与可配置WBP血条后续独立制作。

## 2. 团队快速验收

1. 选车确认进入驾驶：本人和可见其他车辆均有编号与满血条，编号在血条上方。
2. **练习房间本来就抑制HP伤害。** 请Host开始进入正式Playing场地后，再用球／机关测试扣血；普通车碰也不是伤害来源。
3. 检查受击车血条缩短，Host和Client对同一辆车看到一致血量；分别检查高／中／低血量和0血，以及不同MaxHP车型。
4. 打开／关闭菜单，取消确认换车，返回房间并开始第二局：没有旧车血条遗留。

当前尺寸／间距／阈值为临时C++局部常量，没有新增反射参数或全局DA。正式美术调整不在本次范围。
