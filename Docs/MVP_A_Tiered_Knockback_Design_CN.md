# MVP-A 车辆档位制击退企画案

## 1. 目的

将小球命中车辆后的连续物理结果转换为可读、可调的档位结果，在保留 Chaos 刚体碰撞的同时，降低命中点、车身姿态和质量差异造成的异常翻车与击飞波动。

## 2. 核心流程

```text
Launched 小球命中有效车辆
→ 生成 FVehicleHitContext
→ 计算等效撞击速度
→ 选择 Light / Medium / Heavy 档位
→ CombatResolver 结算伤害
→ 按档位施加水平、垂直和旋转结果
→ 小球返回 Free
```

伤害与击退保持分离。球速决定击退档位，但不自动改变基础伤害。

## 3. 撞击强度

MVP-A 使用碰撞方向上的相对速度，并以 Chaos 求解器返回的法向冲量换算值作补充：

```text
相对法向速度 = Abs(Dot(球速度 - 目标命中点速度, 击退方向))
冲量等效速度 = NormalImpulse.Size / 球质量
等效撞击速度 = Max(相对法向速度, 冲量等效速度) × 球的击退倍率
```

该算法使正面高速命中更容易进入高档，擦边或同向追击倾向进入低档。球的击退倍率用于未来特殊球或技能，不复制全局规则。

## 4. 档位结果

| 档位 | 定位 | 默认结果 |
|---|---|---|
| `Light` | 地面击退 | 水平速度变化，不主动增加腾空；清除本次结算时的 Pitch/Roll 角速度以抑制随机翻车 |
| `Medium` | 标准击飞 | 更强水平击退，达到目标向上速度，约一圈翻转 |
| `Heavy` | 强击飞 | 最远水平击退、更高腾空和更强演出 |

档位输出不使用命中点冲量。水平与垂直结果施加在物理质心，使用质量无关的速度变化；翻转角速度单独计算并限制上限，尽量保留 Yaw。

完整一圈只是在无二次碰撞的理想弹道下近似成立。墙面、其他车辆和提前触地仍会改变 Chaos 结果。未来视觉车身可以承担严格的一圈演出，物理车身由空中与落地辅助负责稳定。

## 5. 配置归属

以下内容是全局战斗规则，统一放在：

```text
Project Settings → Game → Vehicle Knockback
```

- Medium / Heavy 的等效撞击速度阈值。
- Light / Medium / Heavy 的水平速度变化。
- Medium / Heavy 的目标垂直速度与翻转圈数。
- 最大空中角速度。
- Light 档地面判定的额外探测距离。

球蓝图只配置：

- 基础伤害。
- `Knockback Strength Multiplier`。

阈值不得散落在不同球蓝图中，以免同一速度在不同资产中得到不可追踪的档位结果。

MVP-A 初始值：

| 参数 | 默认值 |
|---|---:|
| Medium 阈值 | `1000 cm/s` |
| Heavy 阈值 | `2600 cm/s` |
| Light：水平 / 垂直 / 翻转 | `250 cm/s / 0 / 0` |
| Medium：水平 / 垂直 / 翻转 | `600 cm/s / 500 cm/s / 1 圈` |
| Heavy：水平 / 垂直 / 翻转 | `900 cm/s / 750 cm/s / 1.25 圈` |
| 最大空中角速度 | `8 rad/s` |
| 地面探测额外距离 | `20 cm` |

以上只是首轮手感基准，应结合命中日志中的等效撞击速度和 PIE 录像继续调节。

## 6. 稳定性边界

- Chaos 自然碰撞继续存在，但球相对车辆质量较小，主要击飞结果由档位规则提供。
- 不再通过 `AddImpulseAtLocation` 制造不可控的命中点力矩。
- 水平击退投影到世界地面平面；MVP-A 默认场地为平面，未来可改为车辆取得的地面法线。
- Light 档确认目标接地时，会抵消当前向上速度和 Pitch/Roll；已经腾空的目标不会被强制吸回地面。
- 垂直结果采用“达到目标垂直速度”，避免在已经上升时无上限叠加。
- 旋转结果显式控制 Pitch/Roll 并保留 Yaw，且受全局最大角速度限制。
- Physics Sub-stepping 可以提高求解稳定性，但不能替代档位规则、空中辅助与落地辅助。

## 7. 后续扩展

- 按球类型或技能载荷修改击退倍率、强制档位或禁用击飞。
- 使用真实地面法线处理斜坡。
- 将物理旋转与 Procedural Visual Root 的演出旋转分离。
- 增加有限的空中姿态辅助、首次触地检测和落地 PD 辅助。
- 联机阶段由服务器计算档位并复制离散结果，客户端只负责表现与插值。
